# Game Petualangan Sederhana

Game platformer sederhana yang dibuat dengan Python dan Pygame. Kumpulkan koin, hindari musuh, dan selesaikan setiap level untuk menghadapi boss terakhir.

## Persyaratan

- Python 3
- Pygame

## Cara menjalankan

1. Clone repository ini atau unduh file project.
2. Pasang Pygame:

   ```bash
   python -m pip install pygame
   ```

3. Jalankan game dari folder project:

   ```bash
   python platformer_game.py
   ```

## Kontrol

- **Space**: mulai game dan melompat
- **Panah kiri / kanan**: bergerak
- **R**: mulai ulang setelah game selesai atau game over

Game memiliki empat level. Kumpulkan semua koin untuk melanjutkan level, hindari musuh agar nyawa tidak habis, dan sentuh boss untuk mengalahkannya.
